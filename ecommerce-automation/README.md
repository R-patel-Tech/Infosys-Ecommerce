# ecommerce-automation

Selenium + TestNG automation framework for the ecommerce application.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model
- WebDriverManager

## Run

```bash
mvn test
```

## Configuration

Update `src/test/resources/config.properties` for:

- `baseUrl`
- `browser`
- `implicitWait`
- `explicitWait`

## Scope

This project currently focuses on the requested UI automation tasks for:

- Maven project setup
- WebDriver configuration
- Page Object Model structure
- locators
- navigation
- waits
- alerts and popups
- registration
- login
- assertions
